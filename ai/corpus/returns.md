# Returns Policy

## Return Window

You can return most items within 30 days of delivery for any reason. The 30
days run from the date the order was DELIVERED, not from the date it was placed.

Items must be unused, in their original packaging, and complete with any
accessories that came with them.

## How To Return An Item

1. Find the order using your order number and open the order page.
2. Select the items you want to return and the reason.
3. Print the return label we email to you.
4. Hand the parcel in at any drop-off point within 14 days of starting the
   return.

You do not need to contact support first.

## Items That Cannot Be Returned

- Perishable goods, including food and flowers.
- Personalised or custom-made items.
- Earrings and other pierced jewellery, for hygiene reasons.
- Software, music or film with a broken seal.
- Gift cards.

These exclusions do not apply if the item is faulty, in which case your normal
rights apply in full.

## Faulty Items

If an item is faulty you can return it at any point within 12 months. We pay
the return postage and you are entitled to a repair, a replacement, or a full
refund. Faults that appear within 30 days of delivery always entitle you to a
full refund if you want one.

## When We Receive Your Return

We inspect returns within 2 working days of arrival. Once a return is accepted
the refund is issued within 5 working days. If a return is rejected, for example
because the item has been used, we contact you and send the item back at no
cost to you.
